ret2csu

动态libc链接中会有**__libc_csu_int** 这个函数来进行初始化，通过这个函数里面的汇编片段，我们可以很控制到前3个参数和其他的寄存器，也能控制调用的函数地址。

ret2csu的大概思路就是利用csu函数修改函数的返回地址，进行函数地址的泄露，然后再利用写入函数往bss段写入/bin/sh字符串，最后进行系统调用。
用一道[HNCTF 2022 WEEK2]ret2csu作为例题


通过IDA分析我们发现程序中没有system函数和/bin/sh字符串，同时我们可以发现read函数存在严重的栈溢出的漏洞，我们的思路就是多次利用csu函数中的gadget进行伪造函数调用。

通过之前的汇编代码我们可以知道，r13控制rdi，r14控制rsi，r15控制rdx。再通过这个python代码的注释，我们可以发现r12存储的是我们要跳转的函数的地址，同时我们需要设置rbx=0，rbp=1。
接下来我们的做法就是泄露write函数的地址，然后计算出libc的基地址；接着用read函数往bss段写入/bin/sh字符串，最后再调用system函数。


13行的csu_start对应的汇编就是move rdx, r14 ....call [r15+rbx*8]，也就是我们利用的gadget1。作用为把刚才装进去的寄存器，转换成函数调用参数，然后发起调用。
14行的csu_end对应的汇编就是pop rbx....ret，也就是我们利用的gadget2。作用为从栈上把我们伪造好的值装进寄存器，
此处代码27行处对应的调用是write(1, writ_got_addr, 8)，从write_got_addr开始，读取八个字节，之后再跳转到main函数当中。

write函数

write (int fd, const void *buf, size_t count)

参数 寄存器 含义
fd rdi 标准输出
buf rsi 数据的起始地址
count rdx 字节大小

read函数

read(int fd, void *buf, size_t count)

参数 寄存器 含义
fd rdi 标准输入
buf rsi 内存地址
count rdx 字节大小

system函数

system(const char *command)
command：要交给 shell 执行的命令字符串
只需rdi = command。

ZF标志

在csu函数中，一般将rbx赋值为0，rbp赋值为1。在csu函数的汇编中我们可以发现有
add rbx, 0x1，即rbx的值会加一，我们需要使rbp和rbx的值相等，让函数不会进行跳转，这里就会运用到ZF标志位。如果A == B，结果为0，==ZF=1==，如果A!=B，结果为1，==ZF=0==。在cmp rbp, rbx和jne loop中当rbp = rbx的时候，我们就不会进行跳转。
